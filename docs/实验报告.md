## 8 遇到的问题与解决方法

计划内容：问题与解决一一对应，每条写清"遇到了什么 → 为什么 → 怎么解决"。候选：
- 匿名填写与"每人只能填一次"看似矛盾 → 参与记录与答卷分开存
- 本机 MongoDB 不支持事务 → 先登记后写答卷、失败撤回
- 并发修改会互相覆盖 → 条件更新与 `revision` 乐观锁
- 答了被跳过的题怎么处理 → 服务端从头重算路径并拒绝
- 中文 Windows 上 `pip install -r` 失败 → requirements.txt 只用 ASCII
- CSS 覆盖 `hidden` 使按钮误显示 → 全局规则 + 补测试
- 同一毫秒提交的答卷顺序不稳定 → 增加 `_id` 排序条件
