# 测试用例

全部用例都已写成自动测试（pytest），连接真实 MongoDB 的独立测试库 `survey_system_test`，一条命令运行：

```bash
.venv/Scripts/python -m pytest
```

本文按作业要求，列出代表性用例的**测试步骤、输入、预期输出、结果**，并注明对应的测试函数（`文件::函数`），可单独运行，例如 `.venv/Scripts/python -m pytest tests/test_fill.py::test_concurrent_submits_disallowed_only_one`。

"结果"为 2026-10-29 在阶段二代码上的运行结果：全部 410 个测试通过。测试的分类与数量见 [README](../README.md#6-运行测试)。
